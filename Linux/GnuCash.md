# GnuCash

## CSV import settings

These settings live in `~/.local/share/gnucash/books/your_book.gnucash.gcm`.

> **Note**: You may want to back up it along with `your_book.gnucash` file and copy it over when moving between machines.

Ref: https://lists.gnucash.org/pipermail/gnucash-user/2025-September/117416.html
